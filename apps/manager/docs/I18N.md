# Internationalization (i18n)

The manager app uses [Lingui](https://lingui.dev/) for internationalization and [Crowdin](https://crowdin.com/) for translation management.

## Stack

- **Lingui v6** — message extraction, compilation, and runtime
- **Crowdin** — translation platform where translators work
- **PO files** — Gettext format used for catalogs

## Project Structure

```
src/
├── lib/
│   ├── locales.config.ts   # Supported locales and source locale
│   ├── locale.ts           # Locale loading, cookie persistence
│   └── RootProviders.tsx   # I18nProvider setup
└── locales/
    ├── en/messages.po      # Source strings (English)
    └── sv/messages.po      # Swedish translations
```

## Commands

| Command             | Description                                                         |
| ------------------- | ------------------------------------------------------------------- |
| `pnpm i18n:extract` | Extract translatable strings from source code into `en/messages.po` |
| `pnpm i18n:compile` | Compile `.po` catalogs (not required — Vite plugin handles this)    |
| `pnpm i18n:push`    | Upload source strings to Crowdin                                    |
| `pnpm i18n:pull`    | Download translations from Crowdin                                  |

## Developer Workflow

### Adding new strings

1. Wrap strings with Lingui macros in your component:

   ```tsx
   import { Trans, useLingui } from '@lingui/react/macro'

   function MyComponent() {
     const { t } = useLingui()

     return (
       <div>
         {/* JSX content */}
         <h1><Trans>Welcome to ENS</Trans></h1>

         {/* Attributes and variables */}
         <input placeholder={t`Search names...`} />
       </div>
     )
   }
   ```

2. Run extraction to update the source catalog:

   ```sh
   pnpm i18n:extract
   ```

3. Commit the updated `en/messages.po` and merge to `main`.

4. The CI workflow automatically pushes new strings to Crowdin. Translators translate them on Crowdin. Every 4 hours, the CI pulls completed translations and opens a PR.

### Manual push/pull

If you need to sync with Crowdin outside of CI:

```sh
# Push source strings to Crowdin
pnpm i18n:push

# Pull completed translations from Crowdin
pnpm i18n:pull
```

## Adding a New Language

1. Add the locale to `src/lib/locales.config.ts`:

   ```ts
   export const LOCALES = {
     en: 'English',
     sv: 'Swedish',
     fr: 'French', // new
   } as const
   ```

2. Run extraction to generate the new catalog:

   ```sh
   pnpm i18n:extract
   ```

3. Commit and merge. Crowdin picks up the new locale automatically from `crowdin.yml`.

## CI/CD

The GitHub Actions workflow (`.github/workflows/crowdin.yml`) handles sync:

- **On push to `main`** (when `en/messages.po` changes) — uploads source strings to Crowdin
- **Every 4 hours** — uploads sources and pulls translations, opening a PR if there are changes
- **Manual dispatch** — choose to push, pull, or both
